# i18n strategy (FR-first, EN-ready)

## V1 — FR only
- `<html lang="fr">` hard-coded.
- All content in French, in TS data + MDX.
- OG metadata `locale: "fr_FR"`.

## Phase 2 migration path — `next-intl`
1. `pnpm add next-intl`.
2. Move `src/app/*` under `src/app/[locale]/*` with locales `["fr", "en"]`, default `"fr"`.
3. Add `src/i18n.ts` with `getRequestConfig`.
4. Duplicate MDX under `src/content/{fr,en}/` — leave English empty until translated.
5. Update `sitemap.ts` to emit both locales.
6. Add a language switcher in `Header`.

No code churn required in V1 — data and copy are already isolated from components.
