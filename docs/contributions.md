# /contributions

Documents public contributions to the Microsoft ecosystem.

## Model — see `data/contributions.ts`
`kind`: microsoft-learn · github · open-source · community-answer · article · workshop · meetup · webinar · conference · podcast · interview · initiative.

Every entry should carry a verifiable `url`.

## Rule
This page is where "Building toward Microsoft community leadership" is proven. No entry is added without a public source.
